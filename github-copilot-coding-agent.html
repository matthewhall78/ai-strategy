GitHub Copilot

Your AI software engineer

The Coding Agent autonomously resolves GitHub issues — writing code, creating branches, and opening pull requests, all directly from GitHub.com without any local setup.

What can the Coding Agent do?

The Coding Agent is a fully autonomous AI that takes issues from backlog to pull request. It runs inside GitHub Actions, uses real tools, and leaves a traceable audit trail of every decision it makes.

Autonomous issue resolutionCopilot reads your issue, forms a plan, and executes code changes end-to-end without manual intervention.
Branch & pull request creationA dedicated branch is created automatically and a pull request is opened for your team to review.
Iterative feedback loopLeave comments on the pull request and Copilot will read them and revise its work in response.
Runs in GitHub ActionsEvery session is auditable, reproducible, and integrated with your existing CI/CD pipeline and checks.
MCP tool integrationExtend Copilot's reach with custom tools via the Model Context Protocol, giving the agent broader capabilities.

How to use it on GitHub.com

No CLI, no local environment. Assign Copilot directly from any issue page and the agent handles everything from there — all inside your browser.

Enable Copilot in your repositoryGo to your organization or repository Settings → Copilot and enable the Coding Agent feature.
Open a GitHub issueNavigate to the Issues tab of your repository and open the issue you want Copilot to work on.
Assign CopilotIn the Assignees sidebar on the right, click the gear icon and select Copilot from the assignee picker.
Watch the agent workCopilot starts a session in GitHub Actions, creates a branch, and begins writing and testing code changes.
Review the pull requestCopilot opens a PR with its changes. Examine the diff, check the CI results, and leave review comments.
Iterate and mergeReply in the PR conversation with further guidance; Copilot revises its work. Approve and merge when satisfied.
