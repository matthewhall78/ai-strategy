Quickstart

First 30 minutes with context engineering.

This page gives a practical first session: define always-on rules, add one reusable skill, and decide when an agent is justified. The goal is not a perfect setup. The goal is one working pattern your team can repeat.

Open parent concept See skills example Use decision guide

Run this sequence

01

Write one small instructions file

Capture the rules that should apply every time: coding standards, test expectations, naming conventions, and documentation rules. Keep it short enough that the team will actually maintain it.

02

Add one repeatable skill

Pick a workflow that appears multiple times each week. Good candidates are bug triage, migration prep, API review, or security checks. The skill should produce a consistent output shape.

03

Delay agent specialization until it earns its cost

If a role needs different tools, constraints, or review behavior, create an agent. If not, stay with instructions plus skills. Most teams should not start with many agents.

04

Prove value with one real task

Run the setup on a live piece of work and inspect the outcome. Measure whether the output is faster, clearer, or easier to review than the team’s default path.

Rule of thumb: instructions shape behavior, skills shape workflows, and agents shape operating context.

Minimal instructions.md

## Coding Standards
- Use descriptive names.
- Prefer small functions.

## Validation
- Add or update tests for changed behavior.
- Explain any missing validation.

## Documentation
- Document new commands and workflows.

Minimal skills.md idea

Describe one workflow with inputs, steps, and expected output.

Skill: API Review
Input: OpenAPI spec or endpoint diff
Steps:
1. Check naming and versioning
2. Check error contract consistency
3. Flag breaking changes
Output: Findings list + recommended fixes

Use an agent only when

  • The role needs distinct tools or permissions.
  • The role has a different review posture than the default assistant.
  • The role should inherit multiple skills consistently.
