# AI Strategy Pages

This repository contains three standalone HTML pages focused on AI strategy and agentic design concepts.

## Pages

- `agentic_maturity_ladder_single_page_html.html`
- `context_engineering_primitives_html.html`
- `human_intent_agent_execution_html.html`

## Usage

Open any file directly in a browser, or serve the folder with a simple static server.

### Optional local server

If you have Python installed:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
